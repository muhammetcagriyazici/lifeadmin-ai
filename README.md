# 🚀 LifeAdmin AI

LifeAdmin AI, karmaşık hukuki jargonu ve tüketici hakları süreçlerini sadeleştirerek günlük problemlere anında çözüm üreten, LLM ve RAG tabanlı akıllı bir yaşam asistanıdır.

**Microsoft AI Innovators Yaz Stajı** kapsamında geliştirilmiştir.

## 🌟 Özellikler
- **Çift Dil Desteği:** Türkçe ve İngilizce (TR/EN) arayüz.
- **Akıllı Hukuki Analiz:** RAG mimarisi ile kanunlara ve belgelere dayalı durum analizi.
- **Otomatik Metin Üretimi:** Tüketici hakem heyeti dilekçeleri, resmi e-postalar ve WhatsApp mesajları için otomatik taslaklar.
- **Modern Arayüz:** Kullanıcı dostu, "glassmorphism" tasarımlı, tamamen duyarlı (responsive) kontrol paneli.
- **Süreç Takibi:** Devam eden veya çözülen tüketici taleplerini Kanban tarzında takip edebilme.

## 🛠️ Kullanılan Teknolojiler
- **Frontend:** React, Tailwind CSS, Framer Motion, Lucide React
- **Backend & AI:** FastAPI, ChromaDB (Vektör Veritabanı), Microsoft LLM Ekosistemi

## ⚙️ Kurulum ve Çalıştırma
Projeyi kendi bilgisayarınızda çalıştırmak için:
1. Depoyu klonlayın: `git clone https://github.com/muhammetcagriyazici/lifeadmin-ai.git`
2. Klasöre gidin: `cd lifeadmin-ai`
3. Gerekli paketleri yükleyin: `npm install`
4. Uygulamayı başlatın: `npm run dev`
